# Smart Water & Energy Station - Global Solution

Este repositório contém a solução completa para o monitoramento inteligente de água e energia em estações sustentáveis. O projeto é composto por uma API REST desenvolvida em **Java / Spring Boot** e um aplicativo mobile desenvolvido em **React Native / Expo**.

## 🛠️ Tecnologias Utilizadas

### Backend
- **Java 17**
- **Spring Boot 3.x**
- **Spring Data JPA**
- **H2 Database** (em modo arquivo para persistência de dados)
- **Maven**

### Mobile
- **React Native**
- **Expo SDK 51**
- **React Navigation** (Bottom Tabs)
- **Fetch API** (para integração com o backend)
